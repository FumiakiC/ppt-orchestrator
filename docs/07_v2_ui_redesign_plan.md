## 3. 継承契約の要点（詳細は docs/design/v2/04 を正本とする）

**無改変（T0/T1）**: hold.js / polling.js / remote.js / Auth.html 内 JS の 3 関数（`pressKey` / `deleteKey` / `updateDots`）と `form.submit()` 送信経路 / demo-shim.js / build.ps1 / PowerShell 全モジュール（ui-console.ps1 含む。案 B のため）。

**写し替え（T2）**: `src/frontend/views/*.html`（6 ビュー + HtmlHeader）と `src/frontend/css/main.css`。

**新ビューが必ず守る DOM フック**（マスター表は 04 §3。抜粋）:

- 共通: `#connDot` / `#statusPill` / `#offline-overlay`（文言「The show keeps running on the host PC.」維持）/ `#holdhint` / `.container`（`.armed` トグル先）/ `%%TITLE%%` / `%%BUILD_*%%`
- Lobby: `.list-scroll` > `.sec`×2 + `form.deck-form` > `button.deck.hold`（`--chg-*` インライン変数維持）> `.deck-badge` / `.deck-name` / `.deck-cue`、`form#goForm` > `.go-btn` > `.go-main`
- NowPlaying: `%%DECK%%` → `.np .now-name > .nn-track > .nn-seg`、`#elapsed` / `#pos` / `#lockbar` / `#lockSwitch` / `#lockLbl` / `#lockOther` / `#lockOtherMsg` / `#stealBtn` / `#pad .slide-btn[data-cmd]`×6 / `#stopForm` / `#stopBtn`
- Auth: `#authForm` / `#pinDots`（入力済み **`.full`**）/ `#errorMsg` / `#pinValue` / `#submitBtn`
- Dialog: `.dlg-name` / `.pp-next` / `.pp-main-d` + form action `/next` `/retry` `/lobby` `/exit`
- form action パス（`/auth` `/select` `/start` `/stop` `/next` `/retry` `/lobby` `/exit`）は不変。Auth は `form.submit()` のまま（requestSubmit / fetch 化禁止 = Pages モック破壊）

**新規視覚要素の駆動原則**: remote.js が更新しない新要素（進捗バー、プロジェクタタイルの状態文等）は、
**view 内の表示専用 inline script**（例: `#pos` / `.act` を監視する MutationObserver）で駆動し、製品 JS を触らない。

**長押しの見た目**: 進捗リング → ボタン内フィルへ変更するが、`--chgp` を読む CSS の書き換えのみで実現（hold.js 無改変。04 §2.1）。
所要時間はサーバ注入の `data-hold`（1500ms / Exit 系 2000ms）をそのまま使う。
